## Overview
This lesson explains how to create and properly warm up a Facebook Page for advertising assets. It is aimed at media buyers and e-commerce operators who need to structure their Facebook assets to withstand account bans and maintain access across multiple profiles. The instructor demonstrates creating the page at the personal profile level, filling out baseline setup tasks, executing a simple warm-up posting schedule, and delegating admin access.

## Key teachings
- Always create your Facebook Page through a real personal profile rather than inside Business Manager; if a Business Manager gets banned, pages created inside it are lost, whereas profile-level pages are retained [00:00:03].
- Page name and category do not need to be precise or highly branded; generic names work, provided all setup fields are filled out [00:00:29].
- Completing Facebook's recommended page setup checklist makes the page look legitimate to Facebook's automated systems, reducing ban risks [00:01:27].
- You do not need to run a paid ad campaign to get Page likes despite Facebook recommending it in setup tasks [00:02:14].
- Before launching ads, warm up the page by posting generic content and engaging with other accounts for several consecutive days [00:02:52].
- Profile-level pages can still be selected when running ads inside a Business Manager ad account linked to that profile [00:03:46].
- Always assign Facebook Page admin access to your backup personal profiles so that any of the profiles can use the page within their ad accounts [00:04:01].

## Frameworks and models
**Page Setup and Warm-Up Workflow**
1. **Creation:** Log into a real Facebook profile > navigate to Pages > "Create new Page" > fill in Page name, category, and bio [00:00:15].
2. **Profile Completion:** Switch into the page profile > complete checklist tasks (profile picture, cover photo, reel, bio, and contact information; ignore "Run an ad to get more Page likes") [00:01:14].
3. **Warm-Up Protocol:** 
   - Post twice per day for 3 consecutive days before running ads [00:02:52].
   - Content: A generic landscape image (sourced from Google Images) paired with a quote of the day [00:03:07].
   - Engagement: Follow a few pages, like posts, and leave comments [00:03:37].
4. **Redundancy/Access Sharing:** Open Professional dashboard > Page access > add the other two real backup profiles as admins [00:04:08].

## Numbers, benchmarks and rules of thumb
- Warm-up posting frequency: Post 2 times per day [00:02:52].
- Warm-up duration: 3 consecutive days before starting any ads [00:03:00].
- Profile redundancy: Share admin access with 2 other real profiles (3 profiles total) [00:04:18].

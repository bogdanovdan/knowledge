## Frameworks and models

### The 6-Step E-Commerce Execution Cycle
The instructor outlines this evergreen operational system for marketing, product testing, and offer creation [00:06:36, 00:10:39]:

`Study → Research → Create → Test → Feedback Loop → Repeat`

1. **Study**: Learning new information to build your knowledge base [00:10:44].
2. **Research**: Figuring out what people want [00:10:46].
3. **Create**: Communicating how you can help those people get what they want [00:10:48].
4. **Test**: Launching tests in 1 campaign. If it gets spend, it is good; if it does not get spend, it is not good [00:10:51].
5. **Feedback Loop**: Making educated guesses on why your ad, product, or offer is working or not working [00:10:56, 00:11:15].
6. **Repeat**: Going back to research again, or leveraging learnings from the feedback loop to make more assets [00:11:26].

*Operational Loop Rule*: The core daily execution loop is `Create → Test → Feedback Loop → Repeat`. Only drop back into `Research` if the outputs fail, and only drop back into `Study` if research and testing still yield no results [00:07:23, 00:08:18].

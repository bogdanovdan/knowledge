# Mentalidade e hábitos de execução - Regras destiladas
> Fonte: Origins Program (Evolve). Registra o que o curso ensina, não decisões para as marcas da Afterdark. Cada regra cita aula e minuto. Confira na transcrição antes de usar números.

## Feedback loops (núcleo da categoria)
- Ser consistente sem fazer feedback loops ainda tende ao fracasso: fazer o mesmo e esperar resultado diferente. [aula 008, 00:00:00; aula 008, 00:01:29]
- Feedback loop = usar o resultado de um sistema como entrada para mudar ou reforçar as próximas ações dentro do mesmo sistema. [aula 008, 00:01:29]
- Quanto mais feedback loops completados, mais rápido se cresce. [aula 008, 00:03:13]
- Quando um criativo falha, não fugir para "mais media buying e cost caps"; o curso concluiu, após vários loops, que media buying não move a performance e que pesquisar só concorrentes não ajuda a escalar. [aula 008, 00:02:22; aula 008, 00:04:03; aula 008, 00:04:51]
- Fazer loops também sobre o que dá certo (step 1.5), para amplificar. [aula 008, 00:08:26]
- Dá para usar feedback loops de outras pessoas (o curso é o loop do instrutor). [aula 008, 00:05:42]
- Processo do documento: escrever hipóteses, definir ações, cobrar-se pela execução e organizar os loops para depois usar com IA. [aula 008, 00:25:01; aula 008, 00:25:42; aula 009, página da aula]
- Escolher as 1-2 coisas em que você falha repetidamente e as 1-2 em que vai muito bem; uma cópia do documento para cada. [aula 009, página da aula]
- Falha não é fracasso se você completa o feedback loop; cada teste que não deu certo é "um passo mais perto". [aula 011, 00:02:35; aula 011, 00:03:52]

## Ciclo de execução
- Ciclo: estudar -> pesquisar -> criar -> testar -> feedback loop -> repetir. [aula 047, 00:06:13; aula 047, 00:06:52]
- No dia a dia, repetir criar -> testar -> loop; se não avança, voltar para pesquisa; se ainda não avança, voltar a estudar. [aula 047, 00:07:32; aula 047, 00:08:09]
- No teste, "se pega gasto, bom; se não pega gasto, não é bom". [aula 047, 00:10:19]
- Dá para estudar demais; só assistir vídeos não leva aonde você quer. [aula 047, 00:12:45; aula 047, 00:13:26]

## Mudança, dificuldade e horizonte de tempo
- O maior erro de quem não tem sucesso é desistir no "vale do desespero" e pular para outro modelo (TikTok Shop, imóveis), repetindo o ciclo. [aula 006, 00:03:17; aula 006, 00:04:03]
- Sucesso por pura sorte, pulando etapas, é possível, mas o curso o trata como frágil; é na fase difícil que o sucesso é feito, porque "o trabalho trabalha mais em você". [aula 006, 00:04:37; aula 006, 00:05:15]
- Horizontes de 30 ou 60 dias são curtos demais. [aula 006, 00:06:44]
- Regra das 10.000 horas para virar referência; quanto mais nichada a habilidade, mais rápido se chega lá. [aula 007, 00:00:00; aula 007, 00:01:26]
- Quem não se compromete por 3 a 4 anos deve sair do curso. [aula 007, 00:07:50; aula 007, 00:08:31]
- Dificuldade é um filtro entre quem quer e quem merece; "o fato de a maioria desistir é o motivo para você não desistir". [aula 012, 00:00:00; aula 012, 00:01:31]
- Trocar "isso é difícil" por "essa é a parte que faz valer a pena". [aula 012, 00:03:05]
- Um compromisso de 1-2 ou 3 anos de trabalho duro pode mudar a vida, com as ferramentas atuais. [aula 012, 00:13:26]

## Postura de aprendizado
- Mentalidade de faixa branca: dá para aprender com qualquer um, inclusive com quem fatura muito menos (US$ 100/dia vs. US$ 100 mil/dia). [aula 010, 00:00:41]
- Quando se para de aprender, se para de crescer. [aula 010, 00:05:50]

## Números e referências
- US$ 100 mil/mês de receita ≈ US$ 20-30 mil/mês de lucro (contexto do instrutor). [aula 007, 00:00:45]
- 10.000 horas trabalhando todo dia a 8 h/dia = cerca de 3 anos e 5 meses (exemplo da aula). [aula 007, 00:02:55]
- Exemplo do vale: loja que caiu de dias de US$ 5 mil para US$ 500. [aula 006, 00:03:17]
- Comparação 1995 x 2025: desenvolvedor de US$ 80 mil/ano no local vs. cerca de US$ 2.000/mês contratado de qualquer lugar. [aula 012, 00:12:05]

## Conflitos entre aulas
- Horizonte de compromisso: aula 007 pede 3 a 4 anos; aula 012 fala em 1-2 ou 3 anos. Ambas rejeitam prazos de 30-60 dias (aula 006).

## Lacunas
- O curso não detalha métricas para saber em que fase do ciclo emocional você está, além da autoavaliação.
- O curso não detalha com que frequência revisar os documentos de feedback loop.
- O curso não detalha como usar a IA sobre os loops além de "organizar para enviar à IA".

# Knowledge base do Daniel

Fonte única de conhecimento para os bots e LLMs do Daniel (Grok Bot, Claude, Codex e outras).

## Estrutura
- `_global/`: vale para todos (padrão de comunicação, quem é o Daniel, projetos).
- `saude/`: material de treino e nutrição. Sem logs, exames ou dados pessoais de saúde.
- `afterdark/`: holding de marcas DTC (Twelve & Three, RETRO BOY) e mídia paga.
- `quasar/`: software house. Projeto Leilaomaps.

## Regras
- Cada pasta tem um `INDEX.md` que diz o que há nela e quando usar.
- Os arquivos são em Markdown.
- Sem segredos, senhas ou tokens.

## Arquivos de mídia (Google Drive)
Imagens, frames e vídeos não ficam no Git. Eles ficam no Google Drive do Daniel, na pasta `Knowledge` no topo do Meu Drive, com a mesma estrutura de pastas deste repo.
- Raiz: Meu Drive/Knowledge
- No PC do Daniel (Google Drive para desktop): `G:\Meu Drive\Knowledge`
- Exemplo: frames do Origins Program em `Knowledge/afterdark/midia/origins-program/frames/<aula>/` ([pasta](https://drive.google.com/drive/folders/1Uj8jgHgvuemO3v3wTC8ec1J0O65QLy2D))
- Regra: o Markdown do repo aponta para cada arquivo no Drive com link direto. Nunca commitar imagens ou vídeos.

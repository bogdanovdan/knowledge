# Knowledge base do Daniel

Fonte única de conhecimento para os bots e LLMs do Daniel (Grok Bot, Claude, Codex e outras).

## Estrutura
- `_global/`: vale para todos (padrão de comunicação, quem é o Daniel, projetos).
- `saude/`: material de treino e nutrição. Sem logs, exames ou dados pessoais de saúde.
- `afterdark/`: holding de marcas DTC (Twelve & Three, RETRO BOY) e mídia paga.
- `quasar/`: software house. Projeto Leilaomaps.

## Regras
- Cada pasta tem um `INDEX.md` que diz o que há nela e quando usar.
- Os arquivos são em Markdown.
- Sem segredos, senhas ou tokens.
